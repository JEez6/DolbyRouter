# 07 参考与来源

本文汇总实现过程中用到的**官方源码链接**、**第三方项目**与**离线 API 文档**。

## 1. AOSP 源码（判断依据）

均基于 tag **`android-15.0.0_r1`**。

| 内容 | 链接 |
| --- | --- |
| `AudioTrack.cpp`（`set()` / `createTrack_l()` / notification 逻辑） | https://android.googlesource.com/platform/frameworks/av/+/refs/tags/android-15.0.0_r1/media/libaudioclient/AudioTrack.cpp |
| `system/audio.h`（`audio_flags_to_audio_output_flags()`、`AUDIO_FLAG_LOW_LATENCY`、`AUDIO_OUTPUT_FLAG_*`） | https://android.googlesource.com/platform/system/media/+/refs/tags/android-15.0.0_r1/audio/include/system/audio.h |

| OpenSL ES `AudioPlayer_to_android.cpp`（构造 AudioTrack、`notificationFrames=-mNumBuffers`） | https://android.googlesource.com/platform/frameworks/wilhelm/+/refs/tags/android-15.0.0_r1/src/android/AudioPlayer_to_android.cpp |

## 4. 设备端定位的符号与偏移（自证）

对设备 `/system/lib64/libaudioclient.so` 反汇编：

| 项 | 值 |
| --- | --- |
| `_ZN7android10AudioTrack13createTrack_lEv` | `AudioTrack::createTrack_l()` |
| `mFlags` 偏移 | `this + 0x378`（`ldr w8,[x19,#0x378]; and w8,w8,#0xfffffffb; str w8,[x19,#0x378]`） |
| AAudio `_ZN6aaudio25AudioGlobal_getMMapPolicyEv` | 位于 `libaaudio_internal.so`（**不是** `libaaudio.so`） |

常量：

| 常量 | 值 |
| --- | --- |
| `AUDIO_OUTPUT_FLAG_PRIMARY` | `0x2` |
| `AUDIO_OUTPUT_FLAG_FAST` | `0x4` |
| `AUDIO_FLAG_LOW_LATENCY` | `0x100` |

## 5. 验证结论（听感 + dumpsys 一致）

- 8/8 探针后端（Java/OpenSL/AAudio 各性能模式）在 hook 后全部落 `AudioOut_15`（无 FastMixer），effect chain 含 `DAP_offload`。
- `DAP_offload` = Dolby，UUID `9d4921da-8225-4f29-aefa-39537a04bcaa`。
