# 01 背景与目标

## 1. 需求

在小米平板 6 上，让选定的应用在外放（内置扬声器）时获得 **杜比音效（Dolby DAP）**。

原始设想是做一个「按应用切换音频输出接口（OpenSL ES / Java AudioTrack / AAudio）」的 Xposed 模块。
经 AudioProbe 8 后端盲听 + `dumpsys media.audio_flinger` 对照实验，该设想被修正为下面更本质的目标。

## 2. 真正决定杜比的机制（实测结论）

> 决定是否挂杜比的是 **普通混音轨 vs FAST 轨**，与用哪条 API 无关。

| 路径 | 落点 | 杜比 |
| --- | --- | --- |
| Java AudioTrack 普通/旧构造、OpenSL ES 默认（非低延迟） | `AudioOut_15` (deep_buffer，普通轨) | ✅ 有 |
| Java AudioTrack 低延迟、OpenSL `LATENCY_EFFECTS`、AAudio（低延迟与普通） | `AudioOut_D` (PRIMARY\|FAST，FastMixer) | ❌ 无 |

机制：FAST 轨由 FastMixer 直接写 HAL，**绕过普通 mixer 的 effect chain**；Dolby `DAP_offload`
（`/vendor/lib64/soundfx/libhwdap.so`）挂在普通 mixer 输出线程的 effect chain 上。

因此模块目标明确为：**让目标应用的音频落在普通混音轨（非 FAST）**，从而经过 effect chain 挂上 Dolby DAP。

细节见 [02](02-音频栈与Dolby机制.md)。

## 3. 交付形态（已定稿）

- **KernelSU / Zygisk 原生模块**（`zygisk/`）：对**选定应用**的进程做 native inline hook，
  统一覆盖 Java / OpenSL ES / AAudio 三条路径。这是唯一的功能实现载体。
- **`com.dolbyrouter` APK**：只作配置 UI。用户勾选应用 → 写 per-app 名单 → 原生模块读取。
  不再包含 Xposed / LSPosed 代码。

```
┌──────────────────────────────────────────────┐
│  com.dolbyrouter APK (UI)                     │
│  └─ 勾选应用 → shared_prefs/config.xml          │
├──────────────────────────────────────────────┤
│  DolbyRouter Zygisk 模块 (zygisk/arm64-v8a.so) │
│  ├─ root companion 读配置，按包名匹配          │
│  └─ 目标进程内 hook AudioTrack::createTrack_l  │
│     清 FAST/PRIMARY → 落普通轨 → 挂 Dolby DAP  │
└──────────────────────────────────────────────┘
```

## 4. 测试环境与目标设备

> 版本信息来自 2026-10 的实测设备抓取。

| 项 | 值 |
| --- | --- |
| 设备 | Xiaomi Pad 6（型号 `23046RP50C`），codename `liuqin` |
| SoC | Snapdragon 8+ Gen 1（SM8475），`ro.board.platform=taro` |
| 系统 | Android 15（SDK 35），版本串 `AQ3A.250226.002`，MIUI/HyperOS OS3.0 |
| Root 方案 | KernelSU Next（`com.rifsxd.ksunext`），`ksud 3.4.0`（uapi 4，root_ver 33294） |
| Zygisk 实现 | Zygisk Next `zygisksu` **1.5.0 (843-5217106-release)** |
| Xposed 框架 | LSPosed `zygisk_lsposed` **v2.2.0 (7854)**（历史路径，模块已不再依赖） |
| 音频 SKU | `ro.boot.product.vendor.sku=cape`，实际加载 `sku_cape_qssi` |
| 目标应用 ABI | 仅 `arm64-v8a` |

> 说明：本模块只用 Zygisk，不依赖 LSPosed；LSPosed 版本仅用于说明早期实验环境。

## 5. 非目标

- 不修改 Dolby 预设/调音参数本身（那是 `dax-default.xml` 的事）。
- 不保证蓝牙 / USB 外设路径（只针对内置扬声器 `device port 2`）。
- 不做全局粗暴处理（per-app 粒度）。
- **暂不支持**实时低延迟游戏（如喵斯快跑）：其 OpenSL BufferQueue 对时序敏感，强制转普通轨会卡顿。
