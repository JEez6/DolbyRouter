## 4. 源文件职责

### zygisk/jni/src/dolby_router.cpp
- 两个 proxy：`create_track_proxy`（清 `mFlags(this+0x378)` 的 FAST/PRIMARY）、`mmap_get_proxy`（返 0）。
- `install_hooks()`：`shadowhook_init(MODE_UNIQUE)` 后按配置挂 hook；`hook_one()` 统一错误日志。
- `companion_handler`：root 侧读 `perapp.conf`（扁平 `app=`）与 `config.xml`（`scope_<pkg>`），
  返回是否命中给 `preAppSpecialize`。
- `DolbyRouterModule::preAppSpecialize`：取进程名 → connectCompanion → 命中则设原子开关并 `install_hooks()`。

### zygisk/jni/src/abi.h
- `audio_attributes_t` 完整布局（flags @offset12）。
- 常量：`kFlagFast=0x4`、`kFlagPrimary=0x2`、`kAttrFlagLowLatency=0x100`、`kOffAudioTrackFlags=0x378`。
- 函数指针 typedef。

### app 侧
- `MainActivity.java`：总开关 Switch + 已选应用列表（点条目可移出范围）。
- `AppPickerActivity.java`：勾选列表 + 搜索；勾选写 `scope_<pkg>`。
- `PrefsHelper.java`：写 SharedPreferences 后调用 `persist()` 把配置镜像到标准路径并设为 world-readable。
- `hook/XPrefs.java`：仅保留键名常量（`PREFS_NAME` / `KEY_ENABLED` / `PREFIX_SCOPE`）。
- `Insets.java`：Android 15 edge-to-edge padding 适配。

## 6. 修复过的关键 Bug（经验记录）

1. **shadowhook_init errno=12**：`sh_linker_init()` 依赖 `dlopen("libshadowhook_nothing.so")` 握手，Zygisk 环境失败。
   改为直接 `return 0`（该拦截仅服务未使用的 dl_init 回调）。
2. **UNIQUE 模式误用 CALL_PREV 崩溃**：UNIQUE 下无 hub trampoline，必须直接调保存的 `orig`。
3. **mFlags 偏移错误**：早期 `0x11c` 是错的，反汇编确认 `this+0x378`。
4. **AAudio 符号定位**：`AudioGlobal_getMMapPolicy` 在 `libaaudio_internal.so`，不是 `libaaudio.so`。
5. **OpenSL 卡顿**：早期在 `set()` 清 FAST/改 `notificationFrames`，破坏 BufferQueue refill 契约；
   改为只在 `createTrack_l()` 单点清 `mFlags`。
6. **AAudio legacy 落 PRIMARY 输出**：清 FAST 后仍落 `AudioOut_D`，因 AAudio legacy 轨带 `PRIMARY(0x2)`，一并清掉。
7. **负 notificationFrames 校验失败**：AAudio 传 -8，在 set 层清 FAST 后触发 `not permitted for non-fast track`；
   单点方案（不在 set 层动）已避免。
