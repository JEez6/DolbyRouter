# 06 构建与部署

## 1. 主机环境

| 项 | 值 |
| --- | --- |
| Android SDK | `$ANDROID_SDK`（含 `platform-tools` 与 `build-tools 36.1.0`） |
| NDK | r27c（`27.2.12479018`） |
| 大量 JDK | 主机默认 Java 27 与 Gradle 9.5 不兼容 |
| 可用 JDK | `/usr/lib/jvm/`（17/21/25），构建须用 21 |

## 2. Gradle / APK 约束

1. **JDK 必须是 21**：`export JAVA_HOME=/usr/lib/jvm/java-21-openjdk`（否则 Gradle 报 `Unsupported class file major version 71`）。
2. **必须显式 `buildToolsVersion = "36.1.0"`**（`compileSdk release(36)` 会找未安装的 36.0.0）。

## 3. 构建 native 模块

```bash
cd <项目根>/zygisk
bash build.sh          # -> out/zygisk/arm64-v8a.so（~325KB）
bash package.sh        # -> out/DolbyRouter-zygisk.zip（可刷；含 arm64-v8a.so + module.prop + customize.sh）
```

- 依赖：主机 `cmake` + `ninja`；NDK r27c（可用 `NDK` 环境变量覆盖 `build.sh` 中的默认路径）。
- shadowhook 源码在 `jni/third_party/shadowhook/`（上游拷贝，唯一改动为 `sh_linker_init()` 直接 return 0，见 03）。

## 4. 部署到设备（手动，开发用）

```bash
export PATH=$PATH:$ANDROID_SDK/platform-tools
cd <项目根>/zygisk

# 1) push .so 并覆盖模块目录
adb push out/zygisk/arm64-v8a.so /data/local/tmp/dr_arm64.so
adb shell su -c "cp /data/local/tmp/dr_arm64.so /data/adb/modules/dolbyrouter/zygisk/arm64-v8a.so \
  && chmod 0644 /data/adb/modules/dolbyrouter/zygisk/arm64-v8a.so \
  && chcon u:object_r:system_file:s0 /data/adb/modules/dolbyrouter/zygisk/arm64-v8a.so"

# 2) 换 .so 必须重启（zygiskd 只在 post-fs-data 重扫模块）
adb reboot
```

- 模块目录：`/data/adb/modules/dolbyrouter/`（`module.prop`、`zygisk/arm64-v8a.so`、可选 `perapp.conf`）。
- 仅改配置**不需要**重启，force-stop 目标应用重开进程即可。

## 5. 安装 / 运行配置 UI

```bash
cd <项目根>
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk
./gradlew :app:assembleDebug
adb install -r -g app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.dolbyrouter/.MainActivity
```

## 6. 常用调试命令

```bash
adb shell getprop sys.boot_completed        # 1 = 启动完成
adb shell dumpsys trust | grep deviceLocked # 0 = 已解锁

# 模块日志
adb logcat -d -s DolbyRouter:V

# 音频现场
adb shell dumpsys media.audio_flinger       # 看 track 落点 / FastMixer / DAP_offload
adb shell dumpsys media.audio_policy

# 配置（需 root）
adb shell su -c "cat /data/data/com.dolbyrouter/shared_prefs/config.xml"
adb shell su -c "cat /data/adb/modules/dolbyrouter/perapp.conf"

# 音量（stream 3 = MUSIC，max 150）
adb shell cmd media_session volume --stream 3 --set 15

# KernelSU / Zygisk Next
adb shell su -c "ksud module list"
adb shell su -c "znctl status"
```

## 7. 环境备注

- **重启后必锁屏**，锁屏时 `am start` 会报 `Activity class does not exist`，需先解锁。
- KernelSU `su -c` 内嵌单引号会解析失败，改用简单命令或 push 脚本执行。
- 干扰项：SMillet Pro（`com.sidesand.millet`）会冻结目标应用。
- 设备上无 `sqlite3`。
- 探针启动：`adb shell am start -n com.audioprobe/.MainActivity --ei backend <N> --ez play true`
  （2=Java普通 3=Java低延迟 4=AAudio低延迟 5=AAudio普通 6/7=OpenSL 8=OpenSL LATENCY_EFFECTS）。
